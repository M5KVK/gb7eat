**GB7EAT is a Packet Radio BBS located in Eaton Ford, St Neots, Cambridgeshire, UK.**

| RF Port | Details |
| --- | :--- |
| 2m | 144.950MHz 1200 BPS FX.25	User access |

## Hardware

- Raspberry Pi 4 in an ArgonOne case
- Digirig Mobile audio interface
- Tait TM8110 Radio

## Software

- XRPi
- Direwolf Sound Card Modem
